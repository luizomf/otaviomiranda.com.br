Terceira história: a Ówasp explica por que o git status não é somente leitura num repositório hostil.

O tema é rodar Git dentro de um workspace cujo conteúdo é controlado pelo repositório.

O mecanismo. O Git lê a configuração do próprio repositório, e algumas opções apontam um programa para ele executar.

Uma é o monitor do sistema de arquivos, um hook que acelera comandos como o git status.

Como isso chega ao workspace. O guia trata de dois cenários.

Proteger só a pasta ponto git não basta.
